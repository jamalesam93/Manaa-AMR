## 2026-04-15 - [DOM XSS via Dynamic Media Attributes]
**Vulnerability:** Application dynamically assigned URLs to `src` (video/audio/img) and `href` (downloads) attributes directly from user or media sources without validation, making it susceptible to DOM-based Cross-Site Scripting (XSS) if a user supplied an executable scheme (e.g., `javascript:`).
**Learning:** In a single-page app heavily relying on media resources and dynamically rendered attributes, even non-HTML attributes like `href` on dynamically created download links can become execution vectors if they contain javascript payloads. The presence of blob and data URLs for media complicates simple URL validation.
**Prevention:** Implement a rigorous, centralized URL sanitization function (`isSafeUrl` / `getSafeUrl`) that explicitly blocks malicious schemes (`javascript:`, `vbscript:`, `data:text/html`) but allows legitimate media schemes (`blob:`, `data:`). Always wrap dynamic URL assignments to sinks like `href` or `src` with this sanitizer.
