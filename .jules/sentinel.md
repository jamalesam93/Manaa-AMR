## 2024-05-14 - Widespread Insecure Deserialization in LocalStorage
**Vulnerability:** Found widespread insecure deserialization vulnerabilities across multiple utilities (`progressTracker.js`, `streakTracker.js`, `achievements.js`, `dailyChallenge.js`). Data from `localStorage` was being parsed using `JSON.parse` and used immediately without structural or type validation.
**Learning:** Even though `localStorage` is isolated per origin, relying on unvalidated data directly from it risks application crashes (e.g., if a user manually modifies it, or a cross-site scripting flaw allowed an attacker to poison `localStorage`). Furthermore, the errors were logged to console unconditionally, potentially leaking internal state.
**Prevention:** Implement strict type and structure validation immediately after parsing JSON from `localStorage` (e.g., verifying `typeof === 'object'` and `Array.isArray()`, and validating individual property types before assigning them). Wrap `console.error` calls in `if (import.meta.env.DEV)` to avoid leaking information in production.
