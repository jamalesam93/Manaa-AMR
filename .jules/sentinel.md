## 2024-05-18 - [Insecure Deserialization of LocalStorage Data]
**Vulnerability:** The application was directly calling `JSON.parse()` on strings retrieved from `localStorage` across multiple utility files (`AppContext.jsx`, `dailyChallenge.js`, `progressTracker.js`, `achievements.js`, `streakTracker.js`) without type checking or catching exceptions safely (exposing errors in production).
**Learning:** `localStorage` can be modified by the user or malicious scripts (XSS). Blindly parsing its contents without validating the expected type (e.g., `Array.isArray()`, `typeof === 'object'`) can lead to unexpected application state, crashes, or prototype pollution if unvalidated objects are merged into app state. Furthermore, raw stack traces from failed parsing should not be exposed.
**Prevention:** Always wrap `JSON.parse()` in a `try-catch` block. Validate the parsed output against the expected schema or type before returning it. Use optional catch binding for unused errors, and restrict console error logging to development environments (`import.meta.env.DEV`). Ensure utility functions return a fresh copy of default state upon failure to prevent state pollution.
