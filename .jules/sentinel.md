## 2025-02-24 - [CRITICAL] Fix Predictable IDs and Insecure Randomization
**Vulnerability:** Predictable IDs were generated using `Date.now().toString()` (e.g., in `src/utils/progressTracker.js` and `src/contexts/AppContext.jsx`), and `Math.random()` was used for generating random numbers in `src/data/quiz-scenarios.js` (array shuffling).
**Learning:** `Date.now()` is not a secure way to generate unique identifiers as they can be easily predicted, leading to potential Insecure Direct Object Reference (IDOR) vulnerabilities or ID collisions. Similarly, `Math.random()` is not a cryptographically secure Pseudo-Random Number Generator (PRNG) and its sequence of values can be guessed, making it unsuitable for security-sensitive shuffling or operations.
**Prevention:** Always use `crypto.randomUUID()` for generating unique IDs when they must be unpredictable, and `crypto.getRandomValues()` for generating random numbers/shuffling arrays when cryptographic security is required.
