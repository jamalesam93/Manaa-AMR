## 2025-04-21 - [Fix DOM-based XSS via unvalidated URLs]
**Vulnerability:** The application was vulnerable to DOM-based Cross-Site Scripting (XSS) because it dynamically assigned user-provided or unvalidated URLs directly to sensitive HTML attributes like `href` and `src` in `MediaPlayer` and `ImageGallery` components without proper sanitization. This allowed execution of malicious scripts (e.g., via `javascript:` URIs).
**Learning:** React's built-in XSS protection does not automatically sanitize URLs used in `href` or `src` attributes against executable schemes like `javascript:` or `vbscript:`. The use of dynamic URL generation or passing external data without validation to these attributes creates a significant security gap.
**Prevention:** Always validate and sanitize all dynamic URLs using a strict allowlist of protocols (e.g., `http:`, `https:`, `mailto:`) before assigning them to DOM attributes. A utility function (like `getSafeUrl`) should be used centrally for any `href` or `src` bindings to prevent executable schemes from being rendered.
