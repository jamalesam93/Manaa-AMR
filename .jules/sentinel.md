## 2024-04-24 - [DOM-based XSS Prevention via Dynamic Media URLs]
**Vulnerability:** The application was vulnerable to DOM-based XSS through the dynamic assignment of potentially unsafe URLs to `href` and `src` attributes in `MediaPlayer` and `ImageGallery` components without validation. An attacker could potentially inject `javascript:` or `vbscript:` schemes.
**Learning:** React does not automatically sanitize `href` or `src` attributes from custom schemas or inputs, meaning dynamic inputs like `href={url}` can execute code if `url` is `javascript:alert(1)`. When adding dynamic media, returning an empty string for unsafe URLs causes React to render empty attributes (`src=""`), which can cause unintended side-effects (e.g. reloading the page or making requests to base paths).
**Prevention:** Always validate all dynamic URLs for executable schemes before using them in React components. Return `undefined` or `null` for invalid URLs rather than an empty string to ensure React safely skips rendering the unsafe attribute.
