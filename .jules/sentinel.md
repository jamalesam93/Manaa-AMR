## 2025-02-09 - Insecure Deserialization of LocalStorage in Context and Utils
**Vulnerability:** Several features parsing JSON data from localStorage (like familyProfiles in AppContext and dailyChallenge stats) lacked try-catch wrappers or strict structure validation before consumption, creating potential vulnerabilities where manipulated localStorage values could cause runtime crashes or inject malicious objects (prototype pollution/state corruption).
**Learning:** Even though localStorage is client-side, the data should be treated as untrusted user input. Any state constructed from this mechanism in React applications strictly requires defensive decoding with resilient default states and deterministic type verification (e.g. `Array.isArray` or `typeof === object` combined with bounds checking).
**Prevention:** All `JSON.parse` operations extracting local persistence data must be wrapped in `try-catch` blocks with explicit object/array schema validation immediately following successful parse logic. Invalid parses must fallback to safe application defaults securely.
