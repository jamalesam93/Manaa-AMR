## 2026-06-01 - Insecure ID Generation Vulnerability (IDOR)\n**Vulnerability:** Predictable IDs using `Date.now().toString()` for sensitive entities like family profiles and quiz results.\n**Learning:** The application was generating IDs using `Date.now().toString()`, which are predictable and guessable. This could lead to Insecure Direct Object Reference (IDOR) vulnerabilities where an attacker could guess the ID of another user's profile or progress and potentially access or modify it.\n**Prevention:** Use `crypto.randomUUID()` to generate cryptographically secure, non-predictable UUIDs for all entity IDs.
