## 2025-05-15 - DOM-based XSS via Dynamic Anchor Downloads
**Vulnerability:** DOM-based XSS (specifically `javascript:` URI execution) when dynamically assigning user-controlled or potentially tainted URLs to the `href` attribute of dynamically created `<a>` tags used for download functionality (e.g., in `MediaPlayer` and `ImageGallery`).
**Learning:** Even when the primary intent is downloading a file (e.g. using the `download` attribute), if the URL originates from an external source or is dynamically generated without validation, a malicious `javascript:` URI can be assigned to `href` and will execute when `link.click()` is programmatically called.
**Prevention:** All dynamic URL assignments to `href` or `src` attributes must be validated using a security utility (like `isSafeUrl` from `src/utils/security.js`) to block dangerous protocols, their encoded variants, and ensure only whitelisted protocols (http, https, blob, data) or safe relative paths are permitted.
