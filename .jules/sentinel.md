## 2025-04-03 - [CRITICAL] Prevent DOM-based XSS via `javascript:` URIs
**Vulnerability:** Found a CRITICAL vulnerability where a `javascript:` or `vbscript:` URI could be executed when users trigger download functions. The `src` fields on dynamically created `<a>` tags in `ImageGallery.jsx` and `MediaPlayer.jsx` did not validate incoming URLs, allowing execution if an image source gets hijacked or passed maliciously via local states.
**Learning:** `link.href = dynamicSrc` without URL safety validation creates an immediate vector for DOM XSS, particularly in generic download wrappers within media components that parse URLs. Always enforce a safe protocol check prior to dynamically assigning URLs to executable contexts like `<a>` href attributes.
**Prevention:** Created a reusable `isSafeUrl(url)` utility to filter out unsafe protocols (`javascript:`, `vbscript:`), and retrofitted components dynamically setting URL attributes for downloads (`href`) and display (`src`) using this helper.
